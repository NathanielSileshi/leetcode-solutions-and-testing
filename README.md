# LeetCode Problems and Testing

## Overview
A collection of LeetCode problems solved in Java, with custom test cases to validate solutions and explore different algorithms and data structures.

## Technologies
- Java
- Java Collections Framework

## Project Structure
- `problems/` — Algorithm implementations
- `testdata/` — Test inputs and expected outputs
- `runner/` — Runs test cases and reports results

## Problems Solved
- Two Sum
- Contains Duplicate
- Best Time to Buy and Sell Stock

## Goals
- Improve problem-solving skills
- Practice algorithms and data structures
- Compare different approaches and their complexity
